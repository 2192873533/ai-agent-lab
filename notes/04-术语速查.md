# 术语速查

> 读文档、看报错、面试都用得上。

---

## 核心术语

| 英文 | 中文 | 一句话解释 |
|---|---|---|
| LLM | 大语言模型 | 预测下一个词的模型，本质是概率生成器 |
| Agent | 智能体 | 会自己决定"下一步做什么"的程序 |
| Tool | 工具 | **你的代码**，模型只能请求调用，不能自己执行 |
| Tool Call | 工具调用 | 模型发出的"请帮我执行 X"的请求 |
| Context | 上下文 | 你每次发给模型的 messages |
| Message | 消息 | 对话里的一条记录（system/user/assistant/tool） |
| Prompt | 提示词 | 给模型的指令文本 |
| System Prompt | 系统提示词 | 设定模型人设和规则的那条消息 |
| Reasoning | 推理/思考 | 推理模型在正式回答前的内部思考过程 |
| ReAct | 推理+行动 | "想 → 做 → 看"的循环范式 |
| Ablation | 消融 | 故意去掉某个组件，看影响是什么 |
| Grounding | 可依据性 | 答案里的数字有没有出处 |
| Hallucination | 幻觉 | 编造看起来合理但没有依据的内容 |
| Eval | 评估 | 怎么判断 Agent 做得好不好 |
| Trajectory | 轨迹 | 一次任务里所有轮次的完整记录 |
| Token | 词元 | 计费和长度的单位 |

## API 字段

| 字段 | 含义 |
|---|---|
| choices | 候选回答列表（通常只用 [0]） |
| finish_reason | 为什么停下：stop / tool_calls / length |
| message | 那条消息 |
| content | 文本内容 |
| tool_calls | 模型要调用的工具列表 |
| function.arguments | 工具参数（JSON 字符串） |
| tool_call_id | 这次调用的编号，回填结果时要用 |
| usage.total_tokens | 这次花了多少 token |
| reasoning_content | 推理模型的思考过程（部分厂商提供） |

## 常见错误信息

| 报错 | 含义 |
|---|---|
| Missing credentials | API Key 没读到（多半是 os.getenv 参数写错） |
| 401 Unauthorized | Key 无效，或和 provider 不是一家 |
| 404 model not found | provider 和模型名串台 |
| 400 must be a response to a preceding message with tool_calls | tool 消息成了孤儿 |
| 400 tokenization failed | 回传的消息带了对方法不认识的字段 |
| 422 expected a sequence | messages 传了字符串，应该是列表 |
| ModuleNotFoundError | **虚拟环境没激活**（99% 是这个） |
| NameError: name x is not defined | 变量名拼错，或定义在使用之后 |
| SyntaxError: Perhaps you forgot a comma? | 括号内参数间漏了逗号 |

## 三家模型的差异（实测记录）

| 项目 | DeepSeek V4 | Moonshot Kimi K3 |
|---|---|---|
| SDK 对象直接回传 | 宽容，能跑 | 报 tokenization failed |
| 推理模式开关 | extra_body: thinking.enabled | 默认开启，暴露 reasoning_content |
| 内置联网搜索 | 无 | 有（服务端托管 Formula 引擎） |
| 停机信号 | finish_reason | finish_reason |
| 实测幻觉倾向 | 本任务上较保守，会明确拒绝 | 书里记录：去掉约束后编造过汇率 |
