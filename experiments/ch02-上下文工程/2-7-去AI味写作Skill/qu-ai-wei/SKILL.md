# 去 AI 味（中文写作）

## 这是什么

把中文稿子里"一眼看出是机器写的"痕迹删掉，换成人在正常说话时会用的写法。

- 服务谁：要交中文文稿、但不想被看出机器味的人（学生、求职者、自媒体、职场汇报）。
- 合格标准：读者读完之后不觉得这是 AI 写的。**不是"文采更好"，是"更像人"。**

## 作用域

**管**：随笔、感想、个人陈述、求职信、自媒体文章、汇报正文、课程论文的议论部分。

**不管**：公告、合同、技术规范、说明书、学术摘要 —— 这些文体本来就要求程式化表达，
硬去 AI 味会变得不专业。遇到这类，直接说明"这种文体不适合去 AI 味"，不要动手改。

## 四条核心原则

### 1. 一句只说一件事，超过 25 字就断开

- 反面（原稿，一句 39 字）：
  `通过学习大学物理课程，我们可以了解自然界的基本规律和原理，培养科学素养，提高科学素养，对人生观和价值观产生积极的影响。`
- 正面：
  `大学物理讲的是自然界的规律。学完以后，我看事情的方式变了。`

### 2. 写具体的事、具体的场景，不写"影响""意义""价值"

- 反面：`对我的人生观和价值观产生了深远的影响。`
- 正面：`以前刹车时身体前倾，我觉得理所当然。现在会想到反作用力。`

### 3. 一句话说过就不再重复；段末的"总结句"直接删

- 反面：同一段连着两句在说同一件事 ——
  `让我更加珍惜眼前的一切，更加珍视科学的精神。`
- 正面：删掉后一句，段落到"……让我更加谦虚和谨慎"就停。

### 4. 不升华。最后一句可以是一件普通事实

- 反面：
  `我相信，在未来的学习和生活中，我会继续发扬大学物理课程的精神，不断提高自己的科学素养，为建设科学的社会作出更大的贡献。`
- 正面：`这学期我花时间最多的一门课，就是它。`

## 禁止清单

| 禁止 | 为什么 | 合法例外 |
|---|---|---|
| `不仅……更是……` / `不仅……而且……` | AI 腔最明显的指纹，出现即暴露 | 两者确实是递进，且删掉会丢信息 |
| `首先 / 其次 / 此外 / 最后 / 总之` 成串出现 | 人写东西很少这样排 | 操作步骤、清单、需要编号的说明 |
| `对……产生了深远 / 积极的影响` | 空话，不承载信息 | 无 |
| `我们可以……` 作句子主语 | 把"我"藏起来，是机器最爱的主语 | 无 |
| 抽象名词排比（`科学素养、科学思维、实践能力`） | 用名词堆砌代替论证 | 术语表、汇报里的并列项 |
| 无来源的拔高（`具有重要意义`、`作出贡献`） | 空喊口号 | 无 |
| 同义句重复（一段里说两遍同一件事） | 典型的车轱辘话 | 无 |
| `通过……，我们……` 开头 | 万能句式，用多了就是在填模板 | 确实在描述方法与过程时 |

## 怎么改（五步）

1. **数句长**：把超过 25 字的句子标出来，逐句拆开。
2. **圈抽象名词**：影响、意义、价值、素养、能力、思维、理念 —— 能换成动作或例子的就换，换不掉的删。
3. **找重复**：同义句、段末总结句、首尾呼应的"升华"，一律删。
4. **读一遍**：凡是自己读着起鸡皮疙瘩的句子，重写或删掉。
5. **保住事实**：数字、时间、人名、地点、具体事件，一个都不能为了"自然"而丢掉。
